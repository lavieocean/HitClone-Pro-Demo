# HitClone Pro - Claude Artifacts部署指南

## 🎯 项目概述

HitClone Pro是一个专为Claude Artifacts环境设计的AI驱动视频分析工具，支持：
- ✅ **真实Claude API调用** (`window.claude.complete`)
- 📊 **完整的可视化报告** (D3.js图表)
- 🎬 **SRT字幕分析** 和 **视频URL分析**
- 🔄 **4步AI分析链**: 内容提取 → 情感分析 → 参与度分析 → 综合洞察

## 🚀 部署方式

### 方法1: Claude Artifacts直接部署（推荐）

1. **复制构建文件**:
   ```bash
   cat /Users/hmini/Desktop/hitclone-pro/dist-artifact/index.html
   ```

2. **在Claude.ai中创建Artifact**:
   - 打开 [claude.ai](https://claude.ai)
   - 新建对话
   - 说："请帮我创建一个React Artifact"
   - 粘贴上面的HTML内容
   - Claude会自动创建可运行的Artifact

3. **验证环境**:
   - 查看右上角状态指示器
   - 应显示："✅ Claude Artifacts环境" (绿色)
   - 如果显示其他状态，请重新部署

### 方法2: 本地开发模式

1. **启动开发服务器**:
   ```bash
   cd /Users/hmini/Desktop/hitclone-pro
   npm run dev
   ```

2. **访问应用**:
   - 打开: http://localhost:8080
   - 状态指示器会显示："🏠 本地增强模拟模式" (蓝色)
   - 提供智能的模拟API响应

## 📝 使用指南

### 1. 上传SRT字幕文件
- 拖拽或点击上传 `.srt` 格式的字幕文件
- 支持最大5MB文件
- 自动解析并显示文件统计信息

### 2. 开始AI分析
- 点击"开始AI分析"按钮
- 系统将执行4步分析流程：
  1. **内容提取**: 识别主题、语言风格
  2. **情感分析**: 评估情感倾向和情绪分布
  3. **参与度分析**: 计算内容质量指标
  4. **综合洞察**: 生成优化建议和策略

### 3. 查看分析结果
- **可视化图表**: D3.js交互式图表
- **详细报告**: JSON格式的完整分析
- **导出功能**: 可复制或保存结果

## 🔄 重新构建

如需修改代码并重新构建：

```bash
# 开发模式
npm run dev

# 构建生产版本
npm run build

# 构建Artifacts版本
npm run build:artifact
```

构建产物位于: `dist-artifact/index.html`

## 🐛 故障排除

### API连接问题
1. 检查状态指示器颜色
2. 在Claude Artifacts中重新创建
3. 确保使用最新的HTML文件

### 分析失败
1. 检查SRT文件格式是否正确
2. 确保文件大小不超过5MB
3. 查看浏览器控制台错误信息

### 界面问题
1. 刷新页面
2. 清除浏览器缓存
3. 使用最新版本的Chrome/Firefox
